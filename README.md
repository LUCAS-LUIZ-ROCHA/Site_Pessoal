## Sobre o projeto
Este repositório contém meu site/portfólio em arquitetura de página única (SPA-like), com foco em performance, clareza e apresentação profissional.

No site você encontra: apresentação, portfólio, serviços, depoimentos, e formas de contato.

## O que você vai ver (features)
- Layout moderno com Bootstrap 5 e CSS customizado.
- Seções: Início, Portfólio, Serviços, Depoimentos e Contato.
- Componentes responsivos (desktop/tablet/mobile).
- Deploy contínuo na Vercel a partir do GitHub.

## Serviços (resumo)
- Perícia Digital / DFIR: análise forense, resposta a incidentes, triagem e mitigação.
- Cybersecurity: hardening, orientação técnica e boas práticas.
- Software House: desenvolvimento de sistemas e sites sob medida (web).

## Stack
- Backend: Python + Flask
- Frontend: Bootstrap 5 + CSS
- Deploy: Vercel (Serverless)
